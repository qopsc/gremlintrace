### Known open after the fix (deliberate)

`ci/matrix/wildcard-dns.py` forwards **in-zone** queries whose type is not A/ANY (for
example AAAA from `getent ahosts`) to the upstream resolver, which answers NXDOMAIN for the
CI zone. systemd-resolved caches NXDOMAIN per name, so a following A lookup can fail until
the negative TTL expires. The fix is to answer NOERROR with an empty answer section for
in-zone non-A types and forward only out-of-zone names. Deferred: CI-only code; track before
the `installer-matrix` leg is relied on.
